# English Grammar Lab · 高中英语语法实验室

一个生成高中英语语法交互式学习网页的 Agent Skill，以及用该 Skill 的数据与模板制作的完整示例。聚焦“看懂结构—练习判断—获得解析—重练错题”。

## 先打开演示

下载仓库后，双击根目录的 **index.html** 即可使用。无需安装依赖、联网或填写 API Key。它是完整单文件，可以单独发给学生。

请勿直接打开 `assets/template.html`，它是生成脚本使用的模板，不包含已填入的课程数据。分享时发送 `index.html` 文件本身；收件人保存后用浏览器打开，学习记录分别保存在各自浏览器中。

示例包含 **13 个单元、52 道原创教学题，其中 44 道涉及从句**：

| 内容 | 单元 | 题数 |
| --- | --- | --- |
| 基础 | 词性与句子成分、五种基本句型 | 8 |
| 定语从句 | 限定性、非限定性与介词结构 | 8 |
| 名词性从句 | 主语、宾语、表语、同位语 | 16 |
| 状语从句 | 时间、条件、原因、让步、目的与结果 | 20 |

每个单元提供规则、彩色例句拆解、中文释义、判断步骤和易错提醒。练习支持专题、难度和题数筛选；逐题批改，附提示与解析；错题自动收录，重练答对后移除。学习记录可导出 JSON，方便留档。

本版是覆盖核心主题的教学示例，并非完整高中语法课程；比较、地点、方式状语从句、虚拟语气、复杂嵌套等可通过 Skill 继续扩展。题库为原创，不标称真题，也未声称严格对应译林版教材。

## Skill 与网页的关系

**SKILL.md 是交给 AI 的生成工作流；index.html 是学生使用的产物。** Skill 还能根据教师指定的专题、题量、教材材料，改写数据并重新生成网页。因此本仓库既包含可复用技能，也包含可运行的交付示例。

```text
english-grammar-lab/
├── SKILL.md                 技能入口、适用范围与生成流程
├── references/authoring.md  教学与命题约定、数据字段、核对来源
├── data/course.json         原创课程和题库
├── assets/template.html    单文件网页模板
├── scripts/
│   ├── build.mjs            数据校验与 HTML 生成
│   ├── validate.mjs         题库结构校验
│   └── check.mjs            校验与应用状态测试
├── index.html               可直接打开的演示网页
└── README.md
```

## 使用技能

在支持本地 Skill 的 Agent 环境中，将本仓库目录作为 `english-grammar-lab` 技能目录安装，保留所有子目录。不同平台的技能目录以其官方说明为准。也可先让 Agent 阅读本仓库的 `SKILL.md`，再提出生成要求。

示例请求：

> 使用 english-grammar-lab，为高一学生制作一个中文界面的英语定语从句学习网页。讲解关系代词与关系副词的区别，提供 20 道基础到进阶练习，含自动批改、错题重练和逐题解析。输出一个可离线打开的 HTML。

> 根据我提供的教材目录调整课程，重点比较主语、宾语、表语和同位语从句。为每题写清从句功能、连接词的作用及常见误选原因。不要把原创题标成真题。

## 修改与重新生成

需要 Node.js 18 或更高版本；没有第三方依赖。在仓库根目录执行：

```sh
node scripts/build.mjs data/course.json index.html
node scripts/check.mjs data/course.json index.html
```

课程结构与出题原则见 `references/authoring.md`。改动题目内容时应分配新 id；改动课程版本会重置网页读取的旧版学习记录，先导出需要保留的记录。直接双击已有 index.html 无需 Node.js。

## 批改与数据边界

- 单选题、封闭填空题、受控改错使用题库答案判分。填空接受明确列出的合理变体，忽略大小写与多余空白；改错另忽略句末标点，保留内部标点和词序。
- 受控改错要求按题干指定范围输入完整句子；本版本不对自由写作进行语义评阅，也不声称能判断所有自然语言改写。
- 提交后不能更改该题答案，重复点击不会重复记分；“练习正确率”包含重练，不能等同于对能力的正式测量。
- 错题和统计仅存在当前浏览器，无账号、云同步或后台。存储不可用时仍可练习并导出当前内存记录；刷新会丢失未保存内容。刷新不恢复练习进度，已提交的统计通常会保留。
- 导出记录不含姓名，但包含作答内容；没有导入功能。浏览器清理数据、隐私模式或页面路径变化可能影响本地记录。

## 验证

已对课程结构、52 道题的所有接受答案、题库与内嵌数据一致性、空答与重复提交、计分、错题收录和重练移除、筛选、页签切换时保留输入、记录恢复及存储异常执行 Node VM 状态测试。也检查了 Skill 的基础元数据和本地资源链接。

环境未提供可用浏览器，未进行真实浏览器交互、视觉布局或屏幕阅读器测试。提交前建议在 Chrome 或 Edge 中打开 index.html，分别用电脑与手机宽度检查布局，并完成一次“答错—查看解析—错题重练—答对移除”的流程。
