# Grammar Lab · 高中英语语法实验室

用于生成和维护高中英语语法学习网页的 Agent Skill，附可直接使用的完整示例。学习流程是讲解、拆句、语境练习、即时反馈和错题复习。

[打开在线网站](https://english-grammar-lab-904.pages.dev)

## 内容

页面保持原有卡片式学习地图、导航和讲解练习布局；参考框架图只用于整理知识内容，补充被动语态、虚拟语气等。包含22专题、189个速查知识条目和1660道题（含460道新增题）。题面原创，参考位置说明知识来源，不是教材原题的数字化或官方配套题库。

|专题|题数|
|---|---:|
|词性与词形|64|
|句子成分与基本句型|44|
|名词数词、冠词、代词、形容词副词、介词、动词搭配、并列结构|各44|
|比较结构|100|
|时态、被动语态、情态动词、虚拟语气、非谓语动词、主谓一致|各100|
|定语从句、名词性从句、状语从句|各100|
|倒装、强调与特殊句式|各100|
|长难句整合|44|

名词性从句包含主语、宾语、表语、同位语四类；状语从句覆盖时间、地点、条件、原因、目的、结果、让步、方式和比较。重点练习时间参照、逻辑关系、成分空位与易混结构。基础识别题保留，但不再通过轮换人名扩充题库。

## 使用

在线打开上面的地址。双击index.html或grammarlab.html可离线学习；离线文件可以直接发给他人。账号注册/登录和跨设备同步需要在线网址，直接打开本地文件不提供账号服务。

学习地图可搜索知识点，按类别浏览；讲解页提供可展开的知识速查、例句拆解、步骤和易错点。练习可按专题、难度、题型和考点关键词筛选。填空按限定形式作答；新版改错只输入方括号内应替换的内容。

错题本支持重练、打印/另存PDF、下载可编辑DOCX和导出JSON。PDF在报告弹窗的打印目标中选择“另存为PDF”，不是服务器直接生成的PDF附件。

游客记录保存在本浏览器。在线注册后，错题、作答统计及已完成练习汇总同步至账号；游客与账号分别存储，不自动合并。离线待同步记录重新联网后提交，未完成的一组练习不会跨设备续做。用户名3–24位字母、数字、下划线或短横线，密码10–128位；暂不提供密码找回。

## 作为skill使用与维护

SKILL.md为技能入口；data/framework.mjs维护词法与句法框架，data/curriculum.mjs和data/extra-notes.mjs维护讲解。原题保留在data/units，新增题在data/additions，data/difficulty.json逐题明确原题等级，data/course.json为编译数据。每行题源为：

```text
F|考点|含空缺的题面|答案1~答案2|具体判断依据
C|考点|题面|正确选项~干扰项1~干扰项2|具体判断依据
R|考点|含[错误范围]的题面|正确替换内容|具体判断依据
```

F为填空，C为单选，R为受控改错。新增题首列明确带等级，如2F、3C；不得用关键词或题型自动猜难度。中文题面限定必须与答案一致。新增、修改题目要检查多解与语义，不将脚本跑通当作内容审定。旧机械扩题脚本已停用。

```sh
node scripts/compile-course.mjs
node scripts/build.mjs
node scripts/audit-content.mjs
node scripts/check.mjs
```

生成离线单文件不依赖第三方包。联网部署需安装开发依赖：

```sh
npm install
npm run build:pages
npm run deploy:pages
```

当前Cloudflare Pages+D1配置及本地联调见[PAGES.md](PAGES.md)。原Worker方案见[CLOUDFLARE.md](CLOUDFLARE.md)，Node后端为备用方案。

## 验证与边界

校验覆盖题数、结构、知识章节、精确重复、所有列出的可接受答案、错题生命周期、原记录恢复、题型/关键词筛选和报告内容。另使用实际Pages本地运行时验证注册、登录、双会话同步、新旧题重发去重、账号隔离、清空与CSRF。

这些测试不能代替独立教师对所有题目的内容审定。批改针对明确限定答案，不能评估开放写作。原书扫描件、OCR草稿、账号令牌、数据库、work及.wrangler均不应上传。
